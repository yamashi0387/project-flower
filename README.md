# project-flower
Javascriptを触ってみたいという気持ちと、撮影した花の写真でフォトアルバムを作りたいという思いから、このWebサイトの制作に取り組みました。

Claudeと対話をしながら制作を進め、生成されたコードを一行ずつ読み、コメントを残しながら理解を深めました。

Javascriptの簡単なコードが読めるようになったこと、HTMLの様々な機能に触れて理解が深まったことが成果だと考えています。

簡単なものではありますが、AIと対話しながら開発を進めるバイブコーディングの感覚を養うことができました。

Webサイトのリンク：https://yamashi0387.github.io/project-flower/

# 機能
- アコーディオンで写真をグループ表示
- 花の名前での写真検索(alt検索)
- 写真クリックで拡大表示（ライトボックス）
- ハンバーガーメニューからの外部リンク(植物園のHP、自作WEBアプリ)
